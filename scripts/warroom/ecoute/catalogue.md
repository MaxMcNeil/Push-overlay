# Radios et émissions écoutées par la War Room (menu « 📻 Radios et émissions »)

Une ligne par média : `- langue : nom` (langue = fr, en ou ar). Sans adresse, le flux podcast est cherché tout seul à partir du
nom (annuaire public des podcasts). Avec une adresse, elle est utilisée telle quelle : `- langue : nom = https://…/flux.xml`.
Pour une radio écoutée EN DIRECT pendant le lancement (20 min) : `- langue : nom = direct https://…/flux-audio`.
Un média introuvable, injoignable ou sans épisode des dernières 72 h est simplement sauté (une ligne dans le journal).
Tu peux ajouter des noms ici, ou dans le champ « émissions en plus » du workflow, sans aucune règle de nom.
Les flux ci-dessous ont été vérifiés le 26/11/2026.
